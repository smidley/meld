# Plan 26 — links (2026-10-26)

**Goal.** Everything the page names that lives on GitHub is one click from it.

**From the spec.** Section 22 (what the page may do).

**What the owner said.** "Things in the UI that refer to other things like milestones need to link the user to what those milestones or PR are."

## Decisions (each reversible)

1. **One helper spells the host.** `ghUrl(kind, id)` builds every link from the state's own `repo` and `coordination_issue`; it is the single `https://github.com/` in the page, pinned by the no-external-reference test, which otherwise stays as strict as before.
2. **An issue number links to `/issues/<n>` whether it is an issue or a pull request.** GitHub forwards; the page keeps no second list of which numbers are pulls.
3. **A thread comment links to its permalink on the coordination issue**, from the turn's stamp and from the decision card's "on GitHub"; an agreement's ref links to the coordination issue itself.
4. **New tab, no referrer, text without a repository.** `target=_blank`, `rel=noopener noreferrer` beside the page's `no-referrer` meta; `link` falls back to plain text when there is nowhere to go.

## Tasks

1. `app.js` (`ghUrl`, `link`, `refLink`; the header, cards, rows, turns, decision cards, task title), `app.css`; `tests/test_viewer.py`.
2. Spec section 22, `docs/HANDOFF.md`.
